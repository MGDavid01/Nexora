## Hace

1. **R1** Cliente: publicar y listar solicitudes.
2. **R2** Proveedor (`empresa` / `negocio`): listar, aceptar, denegar.
3. **R3–R4** Cotizar / elegir cotización.
4. **R5** Servicios (en `negocio`, una sola cuenta hace oficina y campo).
5. **R6** Historial, equipos, mapa, reclamación en el detalle.
6. **R7** Admin vacío (Reportes, Ingresos, Dispositivos, Auditoría) cuando haya API.
7. **R8** Admin Usuarios: altas `cliente` / `empresa` / `negocio`; autorizar o rechazar conversión (D11).
8. **R9** Perfil `empresa`/`negocio`: pedir conversión; en `empresa`, baja de usuario extra (H8/H9).

R1 luego R2. Maqueta cuando quieras; lista solo con la API en `master`.
